## 核心改进说明

V7在V6基础上新增四大模块：
- **运行模式（Multi-Mode）** ：Quick Scan / Deep Research / Review，按场景选择输出深度
- **执行摘要（Executive Summary）** ：一页式决策摘要，前置，方便快速消费

## 第三步：分析原则（Decision Principles）

1. **风险优先**：先看能不能活下来，再看能赚多少。
2. **概率思维**：不使用绝对化语言，采用高/中/低概率并说明依据。
3. **证据优先**：所有结论标注「事实」「推断」「假设」或「市场预期」，严禁将推测当事实。
4. **多维验证**：重要结论至少需要基本面、市场面、催化剂中的两项以上共同支持。
5. **数据边界**：若缺乏可靠数据，直接输出"无法验证"，不进行臆测。

## 第十二层：预期价值引擎（Expected Value Engine）——新增

**本层将概率与赔率结合，计算期望收益与建议仓位。**

### 输入数据（从第十三层和第十六层获取）

| 情景 | 概率 | 目标价 | 预期收益率 |
|------|------|--------|----------|
| 乐观 | ____% | ______ | +____% |
| 基准 | ____% | ______ | +____% |
| 悲观 | ____% | ______ | ____%（负值为下跌） |

### EV计算
> **EV = (乐观概率 × 乐观收益) + (基准概率 × 基准收益) + (悲观概率 × 悲观收益)**
>
> **EV = ______%**

### 凯利公式参考（可选）
> **凯利比例 f = (p × b - q) / b**
>
> 其中 p = 获胜概率，q = 失败概率，b = 赔率（盈亏比）
>
> **建议仓位参考（凯利的一半，即Half-Kelly）：______%**

### EV评级
| EV范围 | 评级含义 |
|--------|---------|
| EV ＞ 20% | 高赔率机会，强烈考虑 |
| EV 10%~20% | 正期望，值得参与 |
| EV 0%~10% | 正但薄，控制仓位 |
| EV ＜ 0% | 负期望，不建议参与 |

## 输出要求（Output Specification）

1. **模式优先**：先执行"第零步：运行模式选择"，根据模式控制输出深度。

2. **执行摘要必出**：无论何种模式，第一页必须输出执行摘要。

3. **执行顺序固定**：Deep Research模式下严格按流程执行。

4. **证据分级**：所有结论标注「事实」「推断」「假设」或「市场预期」。

5. **证据质量评分**：每层输出证据质量评分（0-10），采用二维评估：
   - **数据可靠性**（0-10）：数据来源可信度
   - **数据时效性**（0-10）：数据新鲜度
   - **综合证据质量 = 可靠性 × 0.6 + 时效性 × 0.4**

6. **数据边界**：对无法可靠获取的数据，输出"无法验证"而非猜测。

7. **量化输出**：概率之和100%，EV明确计算，仓位、止损、止盈量化。

8. **最终输出七项核心结果**：
   - 执行摘要（一页）
   - 最终投资评级 + 决策置信度
   - 预期价值（EV）与建议仓位
   - 市场机制层综合判断
   - 完整交易计划（含仓位管理引擎）
   - 红色/黄色预警清单（What Changes My Mind?）
   - 证据质量与决策置信度总表
